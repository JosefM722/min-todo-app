# 📝 Min Todo App

![Skärmbild](./public/screenshot.png?v=2)

En snygg och modern todo-app byggd med **React + TypeScript + Vite**.

🔗 **Live demo:** https://JosefM722.github.io/min-todo-app

## ✨ Funktioner

- ➕ Lägg till todos
- ✅ Markera som klara (blir ljusa)
- ✏️ Redigera todos (dubbelklicka)
- 🗑️ Ta bort enskilda todos
- 🎯 Filtrera: Alla / Aktiva / Klara
- 💾 Sparas automatiskt i localStorage
- 🧹 Rensa alla klara med ett klick
- 📅 Deadlines med datumväljare
- 🎯 Prioritet (låg/mellan/hög) med färgade remsor
- 🌙 Dark mode
- 🖱️ Drag-and-drop för att ändra ordning
- 🎨 Turkos design med animationer

## 🛠️ Teknik

- React 19
- TypeScript
- Vite
- CSS
- GoatCounter (besöksstatistik)

## 🚀 Kom igång lokalt

git clone https://github.com/JosefM722/min-todo-app.git
cd min-todo-app
npm install
npm run dev

Öppna sedan http://localhost:5173

## 📦 Bygga för produktion

npm run build

## 🌐 Publicera

npm run deploy
